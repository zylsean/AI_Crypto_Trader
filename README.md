AI Crypto Trader

一个从零开始构建的加密货币现货量化研究项目。

1. 项目目标

通过可复现的历史回测、严格的风险控制和逐步验证，研究加密货币现货交易策略的有效性。

项目首先在 iPhone 上使用 Pyto 进行开发，后续计划迁移到电脑环境。

项目不承诺盈利。历史回测表现不代表未来收益。

2. 开发原则

* 先建立小而可靠的回测原型，再逐步增加功能。
* 优先保证数据质量、计算正确性和结果可复现。
* 避免未来数据泄漏（Look-ahead Bias）。
* 回测考虑交易手续费，并逐步完善成交与滑点模型。
* 使用自动化测试验证关键逻辑。
* 保留基准策略，采用训练集、验证集和样本外测试评估策略。
* 逐步进行独立代码审查，避免未经验证的复杂化。
* 每次重要修改都应记录测试结果和项目进度。

3. 安全边界

不做实盘，不使用真实资金。历史研究、回测，以及 OKX 模拟盘现货限价买单验证可以做。模拟盘订单不是真实交易，也不能说明策略有效。

* 不使用真实资金下单。
* 不把模拟盘下单写成真实交易执行。
* 不使用杠杆或做空。
* 不在代码仓库中提交 API 密钥、密码或其他秘密配置。
* 不因单次回测的优秀表现就认定策略有效。

4. 第一阶段范围

* 开发环境：iPhone + Pyto。
* 语言：Python。
* 数据对象：BTC/USDT 现货日线 OHLCV。
* 数据格式：CSV。
* 基准策略：买入并持有。
* 初始研究策略：简单、可解释的移动平均线策略。
* 依赖：优先使用 Python 标准库，确有需要再引入第三方库。

5. CSV 数据格式

目标文件名：BTC_USDT_1d.csv

字段顺序：

timestamp,open,high,low,close,volume

约定：

* timestamp 使用 UTC Unix 毫秒时间戳。
* 日线时间戳对应 UTC 日线起始时间。
* 仅使用已经完整收盘的 K 线。
* 时间戳必须严格递增且不重复。
* 价格必须为有限正数。
* 成交量必须为有限非负数。
* OHLC 数据必须满足基本价格关系。
* 缺失日期应被报告，不应被静默补造。
